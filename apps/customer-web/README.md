# Customer Web

React + Vite app (ADR 0001) for customer-facing experiences — reached via QR
scan, direct link, or WhatsApp message, not organic search, so bundle size
and time-to-interactive on cheap Android phones over patchy 3G/4G matter more
than SSR/SEO.

Responsibilities:

- QR ordering
- Online ordering
- Digital receipts
- Feedback
- Loyalty wallet
- Booking engine later
